# 🔧 Исправление ошибки EPERM

## Проблема:
В терминале видна ошибка:
```
EPERM (Operation not permitted)
syscall: 'kill'
```

Это означает, что процесс не может быть завершен из-за прав доступа.

## Решение:

### Шаг 1: Остановите сервер правильно

В терминале Cursor (внизу окна) нажмите:
- **`Ctrl + C`** (дважды, если нужно)

Это остановит сервер корректно.

### Шаг 2: Перезапустите сервер

В том же терминале выполните:
```bash
npm run dev
```

### Шаг 3: Откройте правильный адрес

В браузере откройте:
```
http://test.localhost:3000
```

**НЕ** `http://localhost:3000` - это вызовет ошибку 404!

---

## ✅ Если не помогает:

### Вариант 1: Закройте все процессы вручную
```bash
# В терминале выполните:
pkill -f "next dev"
lsof -ti:3000 | xargs kill -9
```

### Вариант 2: Перезапустите Cursor
1. Закройте Cursor полностью
2. Откройте снова
3. Откройте терминал (Ctrl + `)
4. Выполните: `npm run dev`

---

## 🎯 Правильная последовательность:

1. **Терминал Cursor**: `Ctrl + C` (остановить сервер)
2. **Терминал Cursor**: `npm run dev` (запустить заново)
3. **Браузер**: `http://test.localhost:3000` (открыть правильный адрес)
4. **Браузер**: Нажать "Sign in"
5. **Терминал Cursor**: Скопировать magic link
6. **Браузер**: Вставить ссылку и Enter

Готово! 🎉
