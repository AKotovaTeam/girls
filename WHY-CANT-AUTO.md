# Почему я не могу выполнить миграцию автоматически?

## 🔒 Технические ограничения:

1. **Supabase JS Client** не поддерживает выполнение произвольного SQL
   - Можно только использовать готовые функции (RPC)
   - Нет метода `executeSQL()` или подобного

2. **Требуется прямой доступ к PostgreSQL**
   - Нужен connection string с полными правами
   - Или доступ через Supabase Management API (требует специальных токенов)

3. **Безопасность**
   - Supabase намеренно не предоставляет публичный API для выполнения SQL
   - Это защищает от SQL injection и несанкционированного доступа

## ✅ Что я сделал вместо этого:

Создал скрипт `auto-migrate.sh`, который:
- ✅ Открывает SQL файл автоматически
- ✅ Открывает Supabase Dashboard в SQL Editor
- ✅ Показывает пошаговую инструкцию

Вам остается только:
1. Скопировать SQL (Cmd+A, Cmd+C)
2. Вставить в Dashboard (Cmd+V)
3. Нажать Run

## 🚀 Альтернативные варианты (если хотите автоматизацию):

### Вариант 1: Supabase CLI
```bash
npm install -g supabase
supabase login
supabase link --project-ref <your-project-ref>
supabase db push
```

### Вариант 2: Использовать psql напрямую
Если у вас есть connection string из Supabase Dashboard → Settings → Database

### Вариант 3: GitHub Actions / CI/CD
Настроить автоматическое выполнение миграций при деплое

## 💡 Рекомендация:

Самый простой способ - использовать скрипт `auto-migrate.sh`, который я создал. Он откроет все необходимое, и вам нужно будет только скопировать-вставить.
