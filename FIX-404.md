# 🔧 Исправление ошибки 404

## ❌ Проблема:

Ошибка: "This domain is not associated with any creator."

Это означает, что тестовый creator не найден в базе данных.

## ✅ Решение:

### Вариант 1: Проверьте и создайте creator вручную

1. Откройте **Supabase Dashboard → SQL Editor**
2. Выполните этот SQL:

```sql
-- Проверяем, есть ли creator
SELECT * FROM creators WHERE slug = 'test-creator';

-- Если нет, создаем
INSERT INTO creators (slug, primary_domain, display_name, bio, included_message_limit, is_active)
VALUES (
  'test-creator',
  'test.localhost:3000',
  'Test Creator',
  'Welcome to my exclusive content platform! Subscribe to get access to premium photos, videos, and direct messaging.',
  20,
  true
) ON CONFLICT (slug) DO NOTHING;

-- Проверяем результат
SELECT * FROM creators;
```

3. После выполнения должна появиться запись с `test-creator`

### Вариант 2: Используйте готовый SQL файл

1. Откройте файл: `check-creator.sql`
2. Скопируйте SQL код
3. Вставьте в Supabase Dashboard → SQL Editor
4. Нажмите Run

## 🔍 Проверка:

После выполнения SQL:

1. В Supabase Dashboard → **Table Editor → creators**
2. Должна быть запись:
   - slug: `test-creator`
   - primary_domain: `test.localhost:3000`
   - display_name: `Test Creator`

## 🚀 После исправления:

1. Обновите страницу в браузере: http://test.localhost:3000
2. Должна загрузиться landing page

## ⚠️ Если все еще не работает:

Проверьте:
1. Правильно ли настроен `.env.local` (выполните `cat .env.local`)
2. Работает ли подключение к Supabase (проверьте логи сервера)
3. Правильно ли настроен домен в `/etc/hosts` (выполните `grep test.localhost /etc/hosts`)
