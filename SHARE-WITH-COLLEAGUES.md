# 🌍 Как дать коллегам протестировать приложение

Сейчас приложение работает только у вас локально (`test.localhost:3000`). Чтобы коллеги могли зайти из интернета — откройте **публичный tunnel**.

## Быстрый старт (2 терминала)

### Терминал 1 — сервер
```bash
npm run dev
```

### Терминал 2 — публичная ссылка
```bash
npm run share
```

Скрипт выведет ссылки вида:
```
https://something.trycloudflare.com/login
```

**Отправьте коллегам ссылку на `/login`.**

После `npm run share` **перезапустите** `npm run dev` (Ctrl+C → снова `npm run dev`), чтобы magic links генерировались с публичным URL.

## Как коллега входит

1. Открывает `https://....trycloudflare.com/login`
2. Вводит свой email → **Send Magic Link**
3. **Вы** копируете magic link из терминала с `npm run dev`
4. Отправляете коллеге в Slack / Telegram / email
5. Коллега открывает ссылку → попадает в Feed

> Magic link одноразовый. Каждый раз после «Send Magic Link» нужна новая ссылка из вашего терминала.

## Платный пользователь для коллеги

В Supabase → SQL Editor выполните `grant-test-subscription.sql`, заменив email коллеги.

## Остановить sharing

Нажмите **Ctrl+C** в терминале с `npm run share`.

Домен автоматически вернётся на `test.localhost:3000`.

## Важно

- Пока tunnel открыт — ваш компьютер должен быть включён и `npm run dev` запущен
- URL меняется при каждом `npm run share` (бесплатный tunnel)
- Не публикуйте `.env.local` — секреты только у вас локально
- Supabase общий для всех тестеров (одна база)

## Альтернатива: деплой на Vercel

Для постоянной ссылки без вашего компьютера — задеплойте на Vercel и обновите `primary_domain` в Supabase на домен Vercel.
