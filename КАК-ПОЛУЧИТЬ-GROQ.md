# 📝 Пошаговая инструкция: Как получить Groq API ключ

## Шаг 1: Откройте сайт Groq

1. Откройте браузер (Chrome, Safari, Firefox)
2. Перейдите по адресу: **https://console.groq.com/**
3. Должна открыться страница регистрации/входа

---

## Шаг 2: Войдите или зарегистрируйтесь

### Вариант A: Вход через Google (самый простой)

1. На странице Groq найдите кнопку **"Sign in with Google"** или **"Continue with Google"**
2. Нажмите на неё
3. Выберите свой Google аккаунт
4. Разрешите доступ (если спросит)

### Вариант B: Регистрация через Email

1. Нажмите **"Sign up"** или **"Create account"**
2. Введите ваш email
3. Придумайте пароль
4. Подтвердите email (проверьте почту)

---

## Шаг 3: Создайте API ключ

После входа:

1. В верхнем меню найдите **"API Keys"** или **"Keys"**
   - Обычно это в правом верхнем углу или в боковом меню
2. Нажмите на **"API Keys"**
3. Нажмите кнопку **"Create API Key"** или **"New Key"**
4. Введите название ключа (например: "My Project" или "Jane Platform")
5. Нажмите **"Create"** или **"Generate"**

---

## Шаг 4: Скопируйте ключ

1. После создания ключа он появится на экране
2. **ВАЖНО:** Скопируйте ключ сразу! Он показывается только один раз
3. Ключ выглядит примерно так: `gsk_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
4. Сохраните его в безопасном месте (например, в Notes)

---

## Шаг 5: Добавьте ключ в проект

1. Откройте файл `.env.local` в корне проекта
   - Если файла нет, создайте его
2. Добавьте строку:
   ```
   GROQ_API_KEY=ваш-ключ-здесь
   ```
   Замените `ваш-ключ-здесь` на скопированный ключ

3. Сохраните файл

---

## Шаг 6: Перезапустите сервер

1. Откройте терминал в Cursor (где запущен `npm run dev`)
2. Остановите сервер: нажмите `Ctrl + C`
3. Запустите снова: `npm run dev`

---

## ✅ Готово!

Теперь Groq подключен. Проверьте:

1. Откройте: `http://test.localhost:3000/app/messages`
2. Отправьте сообщение Jane
3. Она должна ответить через Groq

---

## 🔍 Если что-то не работает:

### Проблема: Не могу найти "API Keys"

**Решение:**
- Попробуйте найти в меню: Settings → API Keys
- Или в профиле: ваш email → API Keys
- Или в Dashboard: слева в меню

### Проблема: Ключ не работает

**Решение:**
- Убедитесь, что скопировали ключ полностью (без пробелов)
- Проверьте, что в `.env.local` нет лишних пробелов
- Убедитесь, что перезапустили сервер после добавления ключа

### Проблема: Не могу зарегистрироваться

**Решение:**
- Попробуйте другой браузер
- Очистите кеш браузера
- Попробуйте через Google аккаунт (проще всего)
