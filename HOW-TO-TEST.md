# 🧪 Как протестировать Magic Link Login

## Пошаговая инструкция:

### Шаг 1: Откройте страницу входа
1. Откройте в браузере: **http://test.localhost:3000**
2. Нажмите кнопку **"Sign in"** или перейдите на **http://test.localhost:3000/login**

### Шаг 2: Введите email
1. Введите любой email (например: `test@example.com`)
2. Нажмите кнопку **"Send Magic Link"**

### Шаг 3: Найдите Magic Link в консоли
1. **Откройте терминал**, где запущен `npm run dev`
2. **Найдите** в логах строки:
   ```
   === MAGIC LINK EMAIL ===
   To: test@example.com
   http://test.localhost:3000/api/auth/callback?token=...
   =======================
   ```
3. **Скопируйте** всю ссылку после `Link:`

### Шаг 4: Откройте Magic Link
1. **Вставьте** скопированную ссылку в адресную строку браузера
2. Нажмите **Enter**
3. Вы будете автоматически перенаправлены на страницу **Feed** (`/app`)

### Шаг 5: Проверьте вход
После успешного входа вы увидите:
- ✅ Ваш email в правом верхнем углу
- ✅ Кнопку "Logout"
- ✅ Навигацию: Feed, Messages, Billing
- ✅ Страницу Feed с постами

## 🎯 Что дальше?

После входа вы можете:
- Просмотреть **Feed** - ленту постов
- Перейти в **Messages** - страницу сообщений
- Проверить **Billing** - информацию о подписке и кредитах

## 💡 Полезные советы:

1. **Если не видите ссылку в консоли:**
   - Убедитесь, что сервер запущен (`npm run dev`)
   - Проверьте, что вы отправили форму (нажали "Send Magic Link")
   - Прокрутите консоль вверх - ссылка может быть выше

2. **Если ссылка не работает (404 Creator not found):**
   - Убедитесь, что скопировали **всю** ссылку из консоли (начинается с `http://test.localhost:3000/api/auth/callback?token=...`)
   - Используйте **`test.localhost:3000`**, а не `localhost:3000`
   - Проверьте, что сервер запущен: `npm run dev`
   - **Проверьте Supabase** — самая частая причина! В терминале сервера не должно быть `ENOTFOUND ...supabase.co`
   - Откройте `.env.local` и убедитесь, что ключи начинаются с `eyJ...` (не `sb_publishable_`)
   - После изменения `.env.local` перезапустите сервер
   - Попробуйте запросить новую ссылку

3. **Для быстрого тестирования:**
   - Можно использовать один и тот же email несколько раз
   - Каждая ссылка работает только один раз
   - Если ссылка истекла, запросите новую
