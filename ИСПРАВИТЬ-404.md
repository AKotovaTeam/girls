# 🔧 Исправление ошибки "404 Creator not found"

## ❌ Проблема:
Ошибка: "404 Creator not found"

Это означает, что система не может найти creator по host header.

## ✅ Решение (по порядку):

### 1. Проверьте URL в браузере

**❌ НЕПРАВИЛЬНО:**
- `http://localhost:3000/app/messages`
- `http://127.0.0.1:3000/app/messages`

**✅ ПРАВИЛЬНО:**
- `http://test.localhost:3000/app/messages`
- `http://test.localhost:3000/` (главная страница)

**Важно:** Должен быть именно `test.localhost:3000`, а не просто `localhost:3000`!

---

### 2. Проверьте /etc/hosts

Выполните в терминале:

```bash
cat /etc/hosts | grep -E "(test\.localhost|admin\.localhost)"
```

**Должны быть записи:**
```
127.0.0.1 test.localhost
127.0.0.1 admin.localhost
```

**Если записей нет, добавьте:**

```bash
sudo bash -c 'echo -e "127.0.0.1 test.localhost\n127.0.0.1 admin.localhost" >> /etc/hosts'
```

Введите пароль Mac, когда попросит.

---

### 3. Проверьте creator в базе данных

1. Откройте **Supabase Dashboard → SQL Editor**
2. Выполните:

```sql
-- Проверяем, есть ли creator
SELECT * FROM creators WHERE slug = 'test-creator';
```

**Если записи нет, создайте:**

```sql
INSERT INTO creators (slug, primary_domain, display_name, bio, included_message_limit, is_active)
VALUES (
  'test-creator',
  'test.localhost:3000',
  'Jane',
  'Welcome to my personal space!',
  20,
  true
) ON CONFLICT (slug) DO NOTHING;
```

**Проверьте результат:**

```sql
SELECT id, slug, primary_domain, display_name, is_active FROM creators;
```

Должна быть запись с:
- `slug`: `test-creator`
- `primary_domain`: `test.localhost:3000`
- `is_active`: `true`

---

### 4. Проверьте .env.local

Убедитесь, что файл `.env.local` содержит:

```bash
NEXT_PUBLIC_SUPABASE_URL=ваш_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=ваш_anon_key
SUPABASE_SERVICE_ROLE_KEY=ваш_service_role_key
ADMIN_HOST=admin.localhost:3000
```

---

### 5. Перезапустите сервер

1. Остановите сервер: `Ctrl + C` в терминале
2. Запустите снова: `npm run dev`
3. Откройте: `http://test.localhost:3000`

---

## 🔍 Диагностика

Если все еще не работает, проверьте логи сервера в терминале:

Должны быть строки:
```
resolveTenant - host: test.localhost:3000
resolveTenant - found creators: [...]
resolveTenant - comparing: "test.localhost" === "test.localhost" = true
resolveTenant - result: test-creator
```

Если видите `resolveTenant - result: null`, значит creator не найден в базе.

---

## ⚡ Быстрое исправление

Если хотите быстро исправить, выполните все шаги по порядку:

1. ✅ Используйте правильный URL: `http://test.localhost:3000`
2. ✅ Проверьте /etc/hosts
3. ✅ Проверьте creator в Supabase
4. ✅ Перезапустите сервер

---

## 💡 Частые ошибки:

1. **Использование localhost вместо test.localhost** - самая частая ошибка!
2. **Creator не активен** - проверьте `is_active = true` в базе
3. **Неправильный primary_domain** - должен быть `test.localhost:3000` (с портом!)
4. **Сервер не перезапущен** - после изменений в базе перезапустите `npm run dev`
