## 🚀 Следующие шаги для тестирования:

### Шаг 1: Откройте главную страницу

В браузере откройте:
```
http://test.localhost:3000
```

Вы увидите красивый лендинг Jane!

---

### Шаг 2: Перейдите на страницу входа

Нажмите кнопку **"Sign in"** или откройте напрямую:
```
http://test.localhost:3000/login
```

---

### Шаг 3: Запросите Magic Link

1. Введите любой email (например: `test@example.com`)
2. Нажмите кнопку **"Send Magic Link"**
3. Вы увидите зеленое сообщение: "✨ Magic link sent!"

---

### Шаг 4: Найдите Magic Link в терминале

1. **Вернитесь к терминалу Cursor** (где запущен `npm run dev`)
2. **Прокрутите вверх** (если нужно)
3. **Найдите блок:**
   ```
   ======================================================================
   🔗 MAGIC LINK EMAIL (Development Mode)
   ======================================================================
   📧 To: test@example.com
   
   🔗 FULL LINK (copy everything below):
   ──────────────────────────────────────────────────────────────────────
   http://test.localhost:3000/auth/callback?token=...
   ──────────────────────────────────────────────────────────────────────
   ```

4. **Скопируйте ВСЮ ссылку** (начинается с `http://test.localhost:3000/auth/callback?token=`)

---

### Шаг 5: Откройте Magic Link

1. **Вставьте** скопированную ссылку в адресную строку браузера
2. **Нажмите Enter**
3. Вы автоматически войдете в систему и будете перенаправлены на страницу **Feed** (`/app`)
