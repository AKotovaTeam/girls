# 🤖 Настройка LLM для Messenger

## Что сделано:

1. ✅ **Создан API route** для отправки сообщений (`/api/messages/send`)
2. ✅ **Интегрирован LLM** (OpenAI) для ответов от имени creator
3. ✅ **Реализована проверка ограничений** - атомарное списание сообщений
4. ✅ **Создан компонент чата** с реальным временем

## Настройка OpenAI API:

### Шаг 1: Получите API ключ

1. Откройте: https://platform.openai.com/api-keys
2. Войдите в аккаунт (или создайте новый)
3. Нажмите "Create new secret key"
4. Скопируйте ключ (он показывается только один раз!)

### Шаг 2: Добавьте в .env.local

Откройте файл `.env.local` и добавьте:

```bash
OPENAI_API_KEY=sk-your-api-key-here
```

### Шаг 3: Перезапустите сервер

```bash
# Остановите сервер (Ctrl+C)
# Запустите снова
npm run dev
```

## Как это работает:

1. **Пользователь отправляет сообщение** → проверяются кредиты
2. **Если кредиты есть** → сообщение сохраняется, кредит списывается
3. **LLM генерирует ответ** от имени creator (Jane)
4. **Ответ показывается в чате**

## Без API ключа:

Если `OPENAI_API_KEY` не установлен, система будет использовать fallback ответы:
- "Hey! Thanks for your message: [ваше сообщение]. I'll get back to you soon! 💕"

## Тестирование:

1. Откройте: `http://test.localhost:3000/app/messages`
2. Если нет разговора - отправьте первое сообщение
3. Система автоматически создаст разговор
4. LLM ответит от имени Jane

## Ограничения:

- **Включенные сообщения**: 20 в период (из подписки)
- **Купленные кредиты**: можно докупить через chat packs
- **Списание**: атомарное (в одной транзакции)
- **Период сбрасывается**: при изменении `current_period_start` в подписке

## Проверка кредитов:

Откройте `/app/billing` чтобы увидеть:
- Сколько включенных сообщений осталось
- Сколько купленных кредитов
- Общее количество доступных сообщений
