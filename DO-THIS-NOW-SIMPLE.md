# 🎯 ЧТО ДЕЛАТЬ СЕЙЧАС - Простая инструкция

## Шаг 1: Выполните SQL миграцию (2 минуты)

1. **Откройте Supabase Dashboard**
   - У вас уже открыт проект "Girls"
   - В верхней панели нажмите **"SQL Editor"** (или ⌘E)

2. **Создайте новый запрос**
   - Нажмите **"New query"**

3. **Скопируйте SQL код**
   - Файл `supabase/migrations/0001_init_white_label.sql` уже открыт в вашем редакторе
   - Выделите весь код: **Cmd+A**
   - Скопируйте: **Cmd+C**

4. **Вставьте и выполните**
   - В SQL Editor: **Cmd+V** (вставить)
   - Нажмите **"Run"** (или Cmd+Enter)

5. **Проверьте результат**
   - Должно появиться сообщение об успехе
   - В левом меню появится "Table Editor"
   - В Table Editor должны быть таблицы

---

## Шаг 2: Получите API credentials (1 минута)

1. В Supabase Dashboard нажмите **Settings** (шестеренка в левом меню)
2. Выберите **API**
3. Скопируйте три значения:
   - **Project URL** → это `NEXT_PUBLIC_SUPABASE_URL`
   - **anon public** key → это `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - **service_role secret** key → это `SUPABASE_SERVICE_ROLE_KEY`

---

## Шаг 3: Настройте .env.local (30 секунд)

В терминале выполните:
```bash
./setup-supabase.sh
```

Скрипт попросит ввести три значения, которые вы скопировали на шаге 2.

---

## Шаг 4: Перезапустите сервер (если нужно)

Если вы изменили `.env.local`, перезапустите сервер:

```bash
# Остановите текущий (Ctrl+C в терминале где запущен npm run dev)
# Запустите снова:
npm run dev
```

---

## Шаг 5: Откройте в браузере

🌐 **http://test.localhost:3000**

Вы должны увидеть красивую landing page для "Test Creator"!

## ✅ Готово!

После выполнения всех шагов проект будет полностью работать!

## 🆘 Если что-то не работает:

- Проверьте, что миграция выполнена успешно
- Убедитесь, что `.env.local` содержит реальные значения (не заглушки)
- Проверьте, что сервер запущен: `lsof -ti:3000`
