# 🔧 Исправление "404 Creator not found" при логине

## ⚠️ Проблема:
При переходе на `/login` появляется ошибка "404 Creator not found"

## 🔍 Причины:

### 1. Неправильный URL
**Самая частая причина!** Вы используете `localhost:3000` вместо `test.localhost:3000`

❌ **Неправильно:**
```
http://localhost:3000/login
```

✅ **Правильно:**
```
http://test.localhost:3000/login
```

### 2. Creator не существует в базе данных

Проверьте в Supabase SQL Editor:

```sql
SELECT 
  id,
  slug,
  primary_domain,
  display_name,
  is_active
FROM creators
WHERE slug = 'test-creator';
```

Если записи нет, выполните:

```sql
INSERT INTO creators (slug, primary_domain, display_name, bio, included_message_limit, is_active)
VALUES (
  'test-creator',
  'test.localhost:3000',
  'Jane',
  'Welcome to my personal space! Subscribe to get access to premium photos, videos, and direct messaging.',
  20,
  true
) ON CONFLICT (slug) DO UPDATE
SET display_name = 'Jane',
    is_active = true;
```

### 3. Проблема с /etc/hosts

Проверьте, что в `/etc/hosts` есть запись:

```bash
cat /etc/hosts | grep test.localhost
```

Должно быть:
```
127.0.0.1 test.localhost
```

Если нет, добавьте:

```bash
sudo bash -c 'echo "127.0.0.1 test.localhost" >> /etc/hosts'
```

## ✅ Решение:

1. **Убедитесь, что используете правильный URL:**
   - Откройте `http://test.localhost:3000/login`
   - НЕ используйте `localhost:3000`

2. **Проверьте creator в базе данных:**
   - Выполните SQL запрос выше
   - Убедитесь, что `is_active = true`

3. **Проверьте /etc/hosts:**
   - Убедитесь, что запись `test.localhost` существует

4. **Перезапустите сервер:**
   ```bash
   # Остановите сервер (Ctrl + C)
   # Запустите снова
   npm run dev
   ```

5. **Проверьте логи в терминале:**
   - При загрузке страницы должны появиться логи:
   - `resolveTenant - host: test.localhost:3000`
   - `resolveTenant - found creators: ...`
   - `resolveTenant - result: test-creator`

## 🐛 Отладка:

Если проблема сохраняется, проверьте логи в терминале где запущен `npm run dev`. Там должны быть сообщения о том, какой host получен и какой creator найден.
