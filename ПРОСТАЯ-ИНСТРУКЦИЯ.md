# 🎯 ПРОСТАЯ ИНСТРУКЦИЯ: Как получить Magic Link

## Шаг 1: Откройте страницу входа

1. Откройте браузер (Chrome, Safari, Firefox)
2. Введите в адресной строке: **http://test.localhost:3000/login**
3. Нажмите Enter

## Шаг 2: Введите email

1. В поле "Email address" введите любой email (например: `test@example.com`)
2. Нажмите кнопку **"Send Magic Link"**

## Шаг 3: Откройте терминал в Cursor

1. В Cursor нажмите на вкладку **"Terminal"** внизу экрана
   - Или нажмите: `Ctrl + `` (клавиша над Tab)
   - Или: меню View → Terminal

2. Вы увидите терминал внизу окна Cursor

## Шаг 4: Найдите Magic Link

1. В терминале прокрутите вверх (если нужно)
2. Найдите блок с текстом:
   ```
   🔗 MAGIC LINK EMAIL (Development Mode)
   📧 To: test@example.com
   🔗 FULL LINK (copy everything below):
   ──────────────────────────────────────
   http://test.localhost:3000/auth/callback?token=...
   ──────────────────────────────────────
   ```

3. **Скопируйте всю ссылку** (начинается с `http://test.localhost:3000/auth/callback?token=...`)

## Шаг 5: Откройте ссылку

1. Вставьте скопированную ссылку в адресную строку браузера
2. Нажмите Enter
3. Вы автоматически войдете в систему!

---

## ❓ Если терминал не виден в Cursor:

### Вариант А: Откройте терминал в Cursor
- Нажмите `Ctrl + `` (клавиша над Tab)
- Или: View → Terminal

### Вариант Б: Откройте отдельный терминал
1. Нажмите `Cmd + Space` (Spotlight)
2. Введите "Terminal"
3. Нажмите Enter
4. В терминале выполните:
   ```bash
   cd /Users/alyona/Cursor_project/Girls
   npm run dev
   ```
5. Теперь в этом терминале будут появляться magic links

---

## 🎬 Полный процесс (кратко):

1. **Браузер**: http://test.localhost:3000/login → введите email → Send
2. **Терминал в Cursor**: найдите ссылку внизу экрана
3. **Скопируйте ссылку** из терминала
4. **Вставьте в браузер** → Enter → готово!

---

## 💡 Важно:

- Magic link появляется в **том же терминале**, где запущен `npm run dev`
- Если сервер не запущен - запустите: `npm run dev` в терминале
- Ссылка работает только один раз
- Если ссылка не работает - запросите новую
