# 🔧 Добавление записей в /etc/hosts

## ⚠️ Важно: Требуется пароль администратора

Для добавления записей в `/etc/hosts` нужны права администратора.

## 🚀 Способ 1: Запустите скрипт

```bash
./add-hosts.sh
```

Скрипт попросит ввести пароль и автоматически добавит записи.

## 🚀 Способ 2: Выполните команду напрямую

Откройте терминал и выполните:

```bash
sudo bash -c 'echo -e "127.0.0.1 test.localhost\n127.0.0.1 admin.localhost" >> /etc/hosts'
```

Введите пароль, когда система попросит.

## ✅ Проверка

После выполнения проверьте, что записи добавлены:

```bash
grep -E "test.localhost|admin.localhost" /etc/hosts
```

Вы должны увидеть:
```
127.0.0.1 test.localhost
127.0.0.1 admin.localhost
```

## 🌐 После добавления

Откройте в браузере:
- http://test.localhost:3000
- http://admin.localhost:3000

## 📝 Примечание

Эти записи нужны для локальной разработки, чтобы браузер мог разрешить домены `test.localhost` и `admin.localhost` на локальный сервер.
