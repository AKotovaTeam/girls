# 🔍 Как найти терминал с npm run dev

## Способ 1: Если терминал уже открыт

1. **Посмотрите на открытые окна терминала**
   - В macOS: найдите окно Terminal или iTerm в Dock или через Cmd+Tab
   - В Windows: найдите окно Command Prompt, PowerShell или Windows Terminal
   - В Linux: найдите окно терминала

2. **Ищите окно с текстом:**
   ```
   ▲ Next.js 14.x.x
   - Local:        http://localhost:3000
   - Ready in X ms
   ```

## Способ 2: Найти процесс в новом терминале

### macOS/Linux:
```bash
# Откройте новый терминал и выполните:
ps aux | grep "next dev" | grep -v grep
```

Или:
```bash
lsof -ti:3000
```

### Windows:
```bash
# В PowerShell или CMD:
netstat -ano | findstr :3000
```

## Способ 3: Запустить новый терминал и проверить

1. **Откройте новый терминал**
   - macOS: `Cmd + Space`, введите "Terminal", нажмите Enter
   - Windows: `Win + R`, введите "cmd", нажмите Enter
   - Linux: `Ctrl + Alt + T`

2. **Перейдите в папку проекта:**
   ```bash
   cd /Users/alyona/Cursor_project/Girls
   ```

3. **Проверьте, запущен ли сервер:**
   ```bash
   # macOS/Linux:
   lsof -ti:3000
   
   # Если команда вернула число - сервер запущен
   # Если ничего не вернула - сервер не запущен
   ```

## Способ 4: Если не можете найти терминал

### Запустите сервер заново:

1. **Откройте новый терминал**

2. **Перейдите в папку проекта:**
   ```bash
   cd /Users/alyona/Cursor_project/Girls
   ```

3. **Запустите сервер:**
   ```bash
   npm run dev
   ```

4. **Теперь этот терминал будет показывать magic links!**

## 💡 Полезные советы:

### macOS:
- Используйте **Cmd + Tab** для переключения между окнами
- Ищите иконку Terminal в Dock
- Используйте **Mission Control** (F3 или жест тремя пальцами вверх) чтобы увидеть все окна

### Windows:
- Используйте **Alt + Tab** для переключения между окнами
- Проверьте панель задач - там могут быть открытые окна терминала

### Linux:
- Используйте **Alt + Tab** для переключения между окнами
- Проверьте все рабочие столы/виртуальные десктопы

## 🎯 Что делать дальше:

После того, как нашли терминал с `npm run dev`:

1. **Оставьте его открытым** - там будут появляться magic links
2. **Когда запросите magic link** (введете email на странице login):
   - Вернитесь к этому терминалу
   - Прокрутите вниз, если нужно
   - Найдите блок с `🔗 MAGIC LINK EMAIL`
   - Скопируйте ссылку

```bash

# 2. Выполните:

```

Теперь этот терминал будет показывать все magic links!
