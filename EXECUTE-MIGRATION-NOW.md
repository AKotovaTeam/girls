## 📝 Выполните миграцию (2 минуты):

### Шаг 1: Откройте SQL Editor

В верхней панели нажмите кнопку **"SQL Editor"** (или используйте ⌘E)

### Шаг 2: Создайте новый запрос

1. Нажмите **"New query"** (или откройте редактор)
2. Вы увидите пустое поле для SQL кода

### Шаг 3: Скопируйте SQL код

1. Откройте файл: `supabase/migrations/0001_init_white_label.sql`
   - Он уже открыт в вашем редакторе
   - Или откройте: `open supabase/migrations/0001_init_white_label.sql`

2. Выделите весь код:
   - `Cmd+A` (выделить все)

3. Скопируйте:
   - `Cmd+C` (скопировать)

### Шаг 4: Вставьте и выполните

1. В SQL Editor в Supabase Dashboard:
   - `Cmd+V` (вставить)

2. Нажмите **"Run"** (или `Cmd+Enter`)

### Шаг 5: Проверьте результат

После выполнения вы должны увидеть:
- ✅ Success message
- В левом меню появится раздел "Table Editor"
- В Table Editor должны быть таблицы: creators, accounts, sessions, и т.д.

## ✅ После выполнения миграции:

1. Получите API credentials:
   - Settings → API
   - Скопируйте: Project URL, anon key, service_role key

2. Настройте .env.local:
   ```bash
   ./setup-supabase.sh
   ```

3. Перезапустите сервер:
   ```bash
   npm run dev
   ```

4. Откройте: http://test.localhost:3000

## 🎉 Готово!

После выполнения миграции проект будет полностью настроен!
