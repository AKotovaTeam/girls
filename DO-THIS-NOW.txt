1️⃣  ДОБАВЬТЕ В /etc/hosts:
   
   sudo bash -c 'echo -e "127.0.0.1 test.localhost\n127.0.0.1 admin.localhost" >> /etc/hosts'


2️⃣  НАСТРОЙТЕ .env.local:
   
   Откройте файл .env.local и замените значения на реальные из Supabase
   
   Где найти:
   - Supabase Dashboard → Settings → API
   - Скопируйте Project URL, anon key, service_role key


3️⃣  ВЫПОЛНИТЕ SQL МИГРАЦИЮ:
   
   - Откройте Supabase Dashboard → SQL Editor
   - Скопируйте содержимое: supabase/migrations/0001_init_white_label.sql
   - Вставьте и выполните (Run)


4️⃣  ОТКРОЙТЕ В БРАУЗЕРЕ:
   
   http://test.localhost:3000
