# ⚠️ ВАЖНО: Правильный адрес!

## ❌ Неправильно:
```
http://localhost:3000
```
Это покажет ошибку 404 "This domain is not associated with any creator"

## ✅ Правильно:
```
http://test.localhost:3000
```
Это откроет лендинг Jane!

---

## 🎯 Правильные адреса:

### Главная страница:
```
http://test.localhost:3000
```

### Страница входа:
```
http://test.localhost:3000/login
```

### Страница подписки:
```
http://test.localhost:3000/subscribe
```

---

## 💡 Почему?

В проекте используется **multi-domain tenancy**:
- Каждый creator имеет свой домен
- Для тестирования создан creator с доменом `test.localhost:3000`
- Простой `localhost:3000` не привязан ни к одному creator

---

## 🔧 Если не работает:

1. **Проверьте /etc/hosts:**
   ```bash
   cat /etc/hosts | grep test.localhost
   ```
   
   Должно быть:
   ```
   127.0.0.1 test.localhost
   ```

2. **Если нет - добавьте:**
   ```bash
   sudo bash -c 'echo "127.0.0.1 test.localhost" >> /etc/hosts'
   ```

3. **Перезапустите браузер** после изменения hosts
