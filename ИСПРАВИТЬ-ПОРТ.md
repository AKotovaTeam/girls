# 🔧 Исправление проблемы с портом

## ❌ Проблема:

Сервер запустился на порту **3001** вместо **3000**:
```
⚠ Port 3000 is in use, trying 3001 instead.
- Local: http://localhost:3001
```

Это означает, что порт 3000 занят другим процессом.

---

## ✅ Решение:

### Шаг 1: Остановите текущий сервер

В терминале Cursor нажмите:
- **`Ctrl + C`**

### Шаг 2: Освободите порт 3000

Выполните в терминале:
```bash
lsof -ti:3000 | xargs kill -9
```

Или:
```bash
pkill -f "next dev"
```

### Шаг 3: Перезапустите сервер

```bash
npm run dev
```

Теперь сервер должен запуститься на порту **3000**.

---

## 🎯 Проверка:

После перезапуска вы должны увидеть:
```
▲ Next.js 14.x.x
- Local:        http://localhost:3000
✓ Ready
```

**НЕ** должно быть сообщения "Port 3000 is in use".

---

## 🌐 Важно:

После исправления используйте правильные адреса:

- ✅ **http://test.localhost:3000** (главная страница)
- ✅ **http://test.localhost:3000/login** (вход)
- ✅ **http://test.localhost:3000/subscribe** (подписка)

**НЕ** используйте порт 3001!

---

## 💡 Если проблема сохраняется:

1. Проверьте, что запущен только один процесс:
   ```bash
   ps aux | grep "next dev"
   ```

2. Остановите все процессы:
   ```bash
   pkill -f "next dev"
   lsof -ti:3000 | xargs kill -9
   lsof -ti:3001 | xargs kill -9
   ```

3. Подождите 2-3 секунды

4. Запустите снова:
   ```bash
   npm run dev
   ```

---

## 🚀 Готово!

После исправления сервер будет работать на правильном порту 3000.
