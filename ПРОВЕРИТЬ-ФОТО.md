# 🔍 Проверка работы фото в сообщениях

## ⚠️ Важно: Выполните миграцию!

Если фото не появляются, убедитесь что миграция выполнена:

1. Откройте **Supabase Dashboard** → **SQL Editor**
2. Скопируйте и выполните SQL из файла: `supabase/migrations/0004_add_message_images.sql`

## 🔍 Отладка:

### 1. Проверьте логи в терминале

Когда Jane отправляет сообщение, в терминале должны появиться логи:
- `[attach-photos] Checking message: ...`
- `[attach-photos] Mentions photo: true/false`
- `[attach-photos] Selected photo: ...`
- `[saveMessageImages] Successfully saved X images`

Если этих логов нет - проверьте что сервер запущен и код обновлен.

### 2. Проверьте базу данных

Выполните в Supabase SQL Editor:

```sql
-- Проверьте есть ли фото в сообщениях
SELECT 
  m.id as message_id,
  m.body,
  m.created_at,
  COUNT(mi.id) as image_count
FROM messages m
LEFT JOIN message_images mi ON mi.message_id = m.id
WHERE m.body LIKE '%photo%' OR m.body LIKE '%link%' OR m.body LIKE '%content%'
GROUP BY m.id, m.body, m.created_at
ORDER BY m.created_at DESC
LIMIT 10;
```

Если `image_count` = 0, значит фото не сохраняются.

### 3. Проверьте что фото загружаются

Откройте консоль браузера (F12) и проверьте:
- Нет ли ошибок при загрузке фото
- Запросы к `/api/messages/[conversationId]/images?messageId=...` возвращают фото

## 🐛 Возможные проблемы:

1. **Миграция не выполнена** - таблица `message_images` не существует
2. **Ключевые слова не срабатывают** - Jane не использует нужные слова
3. **Фото не загружаются** - проблема с путями к файлам
4. **Компонент не обновляется** - нужно обновить страницу

## ✅ Решение:

1. Выполните миграцию
2. Обновите страницу в браузере (F5)
3. Напишите Jane: "Can you show me a photo?"
4. Проверьте логи в терминале
5. Проверьте базу данных
