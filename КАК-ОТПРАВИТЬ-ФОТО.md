# 📸 Как Jane отправляет фото в сообщениях

## ✅ Что реализовано:

1. **Автоматическое прикрепление фото** - когда Jane упоминает фото в сообщении, система автоматически прикрепляет 1-3 случайных фото из папки `public/jane-casual/`

2. **Отображение фото в сообщениях** - фото отображаются прямо в чате под текстом сообщения

3. **Ключевые слова для триггера** - Jane должна использовать слова:
   - "photo", "picture", "pic", "image"
   - "set", "special", "exclusive"
   - "share", "show", "send"

## 🔧 Настройка:

### 1. Выполните миграцию

Откройте Supabase Dashboard → SQL Editor и выполните:

```sql
-- Файл: supabase/migrations/0004_add_message_images.sql
```

### 2. Проверьте наличие фото

Убедитесь, что в папке `public/jane-casual/` есть фото (должно быть минимум 6 файлов .jpg)

### 3. Протестируйте

1. Откройте мессенджер
2. Напишите Jane что-то вроде: "Can you show me some photos?"
3. Jane ответит и автоматически прикрепит фото!

## 💡 Примеры сообщений Jane, которые триггерят фото:

- "I have a special photo set for you"
- "Want to see some pictures?"
- "I took some photos earlier"
- "I can share some exclusive photos with you"

## 🚀 Для production:

В будущем фото будут храниться в Supabase Storage и отдаваться через signed URLs (TTL 10 минут). Сейчас для MVP используются файлы из `public/` папки.
